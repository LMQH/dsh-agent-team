# Code Review Delivery

Review the exact designated diff. Start with correctness, security, data loss, contract compatibility, and regression risk; then cover maintainability and missing verification. Findings must be actionable and evidence-based. Do not approve from summaries alone, do not review your own implementation, and do not claim tests were run unless you ran them.
