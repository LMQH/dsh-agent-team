# Product Delivery

Read current approved requirements and repository evidence. Produce: problem, users, in-scope behavior, explicit non-goals, user flow, measurable acceptance criteria, priority, dependencies, and unresolved decisions. Acceptance criteria must be observable by QA. Never select architecture or treat an assumption as user approval.
