# Quota Governance

Use only supplied or recorded usage data. Segment by task, role, model, duration, retries, tool calls, tokens, and cost. Identify missing data separately from zero usage. Recommend alert, reprioritization, or an authorization request; never cancel tasks, switch models, or rewrite budgets autonomously.
